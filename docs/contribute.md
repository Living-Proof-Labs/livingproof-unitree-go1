# Contribute

Submit focused pull requests and report ordinary bugs through
[repository Issues](https://github.com/Living-Proof-Labs/livingproof-unitree-go1/issues).
Keep runtime changes separate from documentation changes. Edit the README for
package guidance and `docs/` for manual-specific prose; generated files stay in
`artifacts/` and must not be committed.

This manual applies the documentation recipe and docs brand from
[collaboration-guidelines v7.10.9](https://github.com/Living-Proof-Labs/collaboration-guidelines/tree/v7.10.9),
resolved to `c5fa9d9794d0ebd289f51b247fe7872de0db9c27`.
This is scoped documentation adoption; it does not upgrade runtime or release pins.
Current organization/manual/source-directory navigation is a bounded exception to
cross-repository version pinning; executable dependencies and guidance remain pinned.

The repository's [Apache-2.0 license](../LICENSE) applies to its own work.
Playground MJCF and policy are Apache-2.0; Menagerie Go1 meshes are BSD-3-Clause
(Unitree Robotics). Preserve upstream attribution; the build downloads no robot assets.
The shared brand retains its upstream license notice.
No dedicated private security-reporting route is established by this change.
Do not place sensitive reports in public issues.
